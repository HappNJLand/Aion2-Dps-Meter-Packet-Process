# 단축키 입력 참고

## 6-1. 단축키 키 이름 입력 방법

### 수정자 키 (Modifier)
`Ctrl` / `Alt` / `Shift` / `None`

### 일반 키
알파벳·숫자·F1~F12는 그대로 입력합니다.

| 입력값 | 키 |
|--------|-----|
| `R` | R키 |
| `F5` | F5키 |
| `1` | 숫자 1키 |

### 특수 키 이름
기호를 직접 입력하거나 이름으로 입력할 수 있습니다.

| 키 | 입력값 (기호) | 입력값 (이름) |
|----|--------------|--------------|
| `-` (숫자행) | `-` | `MINUS` |
| `=` | `=` | `EQUALS` |
| `,` | `,` | `COMMA` |
| `.` | `.` | `PERIOD` |
| `/` | `/` | `SLASH` |
| `;` | `;` | `SEMICOLON` |
| `'` | `'` | `APOSTROPHE` |
| `` ` `` | `` ` `` | `GRAVE` |
| `[` | `[` | `LBRACKET` |
| `]` | `]` | `RBRACKET` |
| `\` | `\` | `BACKSLASH` |

### 넘패드 키
넘패드 키는 일반 키와 **다른 이름**을 사용합니다. (`-`와 `NUMMINUS`는 별개)

| 키 | 입력값 |
|----|--------|
| 넘패드 0~9 | `NUMPAD0` ~ `NUMPAD9` |
| 넘패드 `+` | `NUMPLUS` |
| 넘패드 `-` | `NUMMINUS` |
| 넘패드 `*` | `NUMMULTIPLY` |
| 넘패드 `/` | `NUMDIVIDE` |
| 넘패드 `.` | `NUMDECIMAL` |
| 넘패드 Enter | `NUMENTER` |

### 기타 키

| 키 | 입력값 |
|----|--------|
| 방향키 | `UP` / `DOWN` / `LEFT` / `RIGHT` |
| Page Up / Down | `PAGEUP` / `PAGEDOWN` |
| Home / End | `HOME` / `END` |
| Insert / Delete | `INSERT` / `DELETE` |
| Enter / ESC / Tab | `ENTER` / `ESC` / `TAB` |
| Backspace | `BACKSPACE` |
| Print Screen | `PRINTSCREEN` |
| Scroll Lock | `SCROLLLOCK` |
| Pause | `PAUSE` |
| Caps Lock | `CAPSLOCK` |
| Num Lock | `NUMLOCK` |
| 윈도우키 (좌/우) | `LWIN` / `RWIN` |
